## 🔐 Security & Data Protection

### Firestore Security Rules Flow

```
User submits feedback
        │
        ▼
Is user authenticated?  NO  → ❌ Reject
        │ YES
        ▼
Can read own feedback?
        │
        ├─→ request.auth.uid == resource.data.uid  → ✅ Allow
        │
Creating new feedback?
        │
        ├─→ uid in document matches currently
            authenticated user  → ✅ Allow
        │
        ├─→ Otherwise  → ❌ Deny
```

## 📈 Performance & Limits

### Processing Timeline

```
User Submits Form (Timeline)
│
├─ 0ms:    Form submitted
├─ 100ms:  Data validated
├─ 200ms:  Firestore write initiated
├─ 500ms:  Document created in Firestore
├─ 600ms:  Cloud Function triggered
├─ 800ms:  Function reads Firestore data
├─ 1000ms: HTML email formatted
├─ 1500ms: SendGrid SMTP connection established
├─ 2000ms: Email queued with SendGrid
├─ 3000ms: Success message shown to user
│
└─ 5000ms: Email delivered to inbox
           (depends on recipient server)
```

### Quotas & Limits

| Item | Limit | Cost |
|------|-------|------|
| Firestore Reads | 50,000/day | Free |
| Firestore Writes | 20,000/day | Free |
| Cloud Function Invocations | 2M/month | Free |
| SendGrid Emails (Free) | 100/day (3,000/month) | Free Tier |
| SendGrid Emails (Paid) | Unlimited | $14.95/month+ |
| Function Timeout | 60 seconds | Default |

## 🎯 Status Codes & Meanings

### Email Status Values

```
status: "pending"
└─ Feedback collected but not yet sent
   (Use this if email sending fails initially)

status: "sent"
└─ Successfully submitted and queued for email
   (This is what the app sets)

status: "read"
└─ Developer has read the email
   (Manual update if tracking is needed)
```

## ⚡ Quick Decision Tree

```
Email not arriving?
│
├─ Check Spam/Promotions folder
│  └─ Move to Primary
│
├─ Check Firestore document created
│  └─ If not → Check app form validation
│
├─ Check Cloud Function logs
│  ├─ If error shown → Check API Key
│  └─ If success shown → Wait 5 mins, check spam
│
├─ Check SendGrid dashboard
│  ├─ Bounces section → Check for bounce
│  └─ Activity section → Check delivery status
│
└─ If all above OK → Contact SendGrid support
```
